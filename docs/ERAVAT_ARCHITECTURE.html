0. CTO brief (read this first)

Eravat is a life-safety-adjacent field operations tool for MP Forest Department elephant monitoring. The engineering bet is: one reliable offline-first app + one managed Postgres/PostGIS backend, not a microservice estate. Success is measured by field staff filing reports without signal, officers getting timely alerts, and data staying territory-scoped.

What you own as CTO

  • Architecture style: modular monolith + BaaS (locked)
  • Staging vs production promotion discipline
  • Security / key rotation / RLS debt
  • Go-live gates (SMS, push, pilot accounts)
  • $0 telemetry posture (PostHog free + billing caps)
  • What we explicitly will not build yet (Kafka, custom API farms)

What “done” looks like for a pilot

  • Signed Android APK on staging/prod with correct env
  • Offline report + photo sync works after reconnect
  • Chain-of-command / proximity alerts fire for scoped officers
  • Only enrolled phones can auth (no ghost users)
  • Backups landing on Eravat Drive nightly
  • No service_role secrets in git or client bundles

1. System overview

Eravat is a mobile-first Progressive Web App (and Capacitor Android build) for the Madhya Pradesh Forest Department to log elephant activity (direct sightings, indirect signs, conflict/loss) in low-connectivity field conditions. Geography is seeded at 11 divisions → 80 ranges → 1,222 beats with PostGIS polygons.

Architecture verdict

This is a modular monolith on a BaaS — not microservices. One React app (eravat-app/), one Postgres database, shared Auth/Storage/Realtime, and a handful of Deno Edge Functions for privileged operations. Edge functions are serverless helpers on the same project — not independently owned domain services.

Auth reality vs documentation drift

Do not trust a single doc for auth ERAVAT_SOURCE_OF_TRUTH, AUTH_ARCHITECTURE, and GO_LIVE_OPS disagree in places (password vs OTP-only, PIN present vs removed). Treat live code (Login.tsx, AuthContext.tsx, Supabase Auth settings) as source of truth per environment.
